# RakuTube

YouTubeの共有ボタンの右隣にダウンロードボタンを追加するChrome拡張機能です。

ボタンを押すと、[y2down](https://y2down.cc/jaWa/)への動画URLの入力から、解像度の選択、処理の開始までを自動で行います。

> [!NOTE]
> 本プロジェクトは、人間の監督のもと、GPT-6.1-solが作成しました。

## インストール

1. リリースのZIPファイルをダウンロードし、任意のフォルダに展開します。
2. Chromeで chrome://extensions を開き、「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、展開したフォルダを選択します。

インストール後、YouTubeの動画ページを再読み込みすると、ダウンロードボタンが表示されます。展開したフォルダは拡張機能の実行に必要なため、そのまま保管してください。

## 使い方

動画ページでダウンロードボタンを押すと、次の操作が順番に実行されます。

1. [y2down](https://y2down.cc/jaWa/)のタブが開いていれば、そのタブを使います。開いていなければ新しいタブを開きます。
2. https://youtu.be/動画ID の形式で動画URLを入力します。siなどのクエリは除去します。
3. 設定した解像度を選択します。
4. サイト側のダウンロードボタンを一度クリックし、処理を開始します。

動画ファイルを保存するためのダウンロードボタンは、y2down側の処理が完了すると表示されます。初期設定では、その保存先をバックグラウンドのタブで開きます。表示中のタブは切り替わりません。動画を続けて追加した場合も、先に完了したものから保存用ページを開きます。

## 設定

拡張機能のアイコンから設定を変更できます。設定は自動保存されます。

対応する解像度は4K、1440p、1080p、720p、480p、360p、240p、144pで、初期値は1080pです。

「完了したものからDLする」は初期値がオンです。オフにすると保存ボタンを手動でクリックできます。この設定の変更は、処理中の動画にも反映されます。解像度の変更は、次に追加する動画から適用されます。

## 更新

ファイルを更新したら、chrome://extensions でRakuTubeを再読み込みし、YouTubeの動画ページと、開いているy2downのページも再読み込みしてください。

## 対応範囲と制限

PC版YouTubeの通常の動画ページに対応しています。共有ボタンは日本語・英語表示が対象です。Shortsには対応していません。

設定した解像度が選べない場合や入力欄を操作できない場合は、エラーを表示して操作を停止します。処理開始後はy2down側で操作を続けてください。

サイト側のダウンロードボタンをそのままクリックするため、サイトが設定した広告の処理も実行されます。Chromeがポップアップを制限する場合があります。
